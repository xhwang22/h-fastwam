## Key Architecture Summary

### Video Expert (WanVideoDiT)
- **24 DiT Blocks**: Self-Attention (3D RoPE) → Cross-Attention (Text) → FFN
- **Dimensions**: hidden_dim=1280, num_heads=20, attn_head_dim=64, ffn_dim=3456
- **Input**: VAE latents [B, 16, T/4, H/8, W/8]
- **Processing**: Patchify → Time/Text/Action Embedding → Tokens
- **Output**: Predicted video latents [B, 16, T/4, H/8, W/8]

### Action Expert (ActionDiT)
- **24 DiT Blocks**: Identical architecture to video expert for MoT compatibility
- **Same Dimensions**: hidden_dim=1280, num_heads=20, attn_head_dim=64, ffn_dim=3456
- **Input**: Noisy actions [B, T_action, 7]
- **Processing**: Action Encode → Time/Text Embedding → Tokens
- **Output**: Predicted actions [B, T_action, 7]

### VAE (WanVideoVAE)
- **Encoder**: 23 CausalConv3d layers (1 init + 4×4 stages + 3 middle + 1 head)
- **Compression**: Temporal 4× + Spatial 8×, z_dim=16
- **Input**: Video frames [B, 3, T, H, W]
- **Output**: Latents [B, 16, T/4, H/8, W/8]
- **Key Components**: ResidualBlocks, AttentionBlock, CausalConv3d

### Mixture of Transformers (MoT)
- **Mixed Attention**: Video and action tokens attend together
- **Attention Mask Structure**:
  - Video-to-Video: Per-frame causal
  - Video-to-Action: All allowed (video sees all actions)
  - Action-to-Video: Group causal (actions see first frame only)
  - Action-to-Action: All allowed (bidirectional)
- **24 Shared Blocks**: Enhanced with mixed-modal attention

### Noise Scheduling
- **Type**: Continuous Flow Matching (WanContinuousFlowMatchScheduler)
- **Timesteps**: 1000 for both video and action
- **Operations**: 
  - `sample_training_t()`: Random t ∈ [0, 1]
  - `add_noise()`: x_t = α(t)·x + σ(t)·ε
  - `training_target()`: Compute target for MSE loss
  - `training_weight()`: Timestep-based loss weighting

### Loss Computation
```
loss_total = λ_video · loss_video + λ_action · loss_action

where:
  loss_video = MSE(pred_video, target_video) with image_is_pad masking
  loss_action = MSE(pred_action, target_action) with action_is_pad masking
  λ_video, λ_action: configurable weights (default 1.0)
```

## Training Data Flow (High-Level)

```
Raw Sample (video, text, action, masks)
    ↓
VAE Encode: [B, 3, T, H, W] → [B, 16, T/4, H/8, W/8]
    ↓
Add Noise: sample t, add noise to latents and actions
    ↓
Video Expert pre_dit: Patchify, embed time/text/action
    ↓
Action Expert pre_dit: Embed actions, time, text
    ↓
Build MoT Attention Mask: Connect video/action with causal rules
    ↓
Mixture of Transformers: 24 blocks of mixed attention
    ↓
Video Expert post_dit: Project to latent predictions
Action Expert post_dit: Project to action predictions
    ↓
Compute Loss: MSE with padding masks and timestep weighting
    ↓
Return: loss_total, loss_dict (for optimizer)
```


## Key Technical Concepts

### Diffusion/Flow Matching
- Gradual corruption of data with noise
- Model learns to predict noise or velocity
- Timestep-dependent noise scheduling
- Training loss weighted by SNR or similar metric

### Mixture of Transformers
- Unified attention space for multiple modalities
- Video and action tokens share DiT blocks
- Attention mask controls cross-modal interaction
- Group causal: actions see first frame only

### Rotary Position Embeddings (RoPE)
- Video: 3D RoPE (temporal, height, width)
- Action: 1D RoPE (sequence position)
- Applied only in self-attention (not cross-attention)
- Precomputed for efficiency

### Adaptive Layer Normalization (AdaLN)
- 6 parameters per block: shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp
- Derived from timestep embedding
- Controls strength of attention and FFN contributions

### Group Causal Masking
- Action tokens attend only to first video frame
- Prevents action conditioning on future video states
- Enforces temporal consistency
- Grouped by tokens_per_frame
