│    │  3D RoPE       │  Mixed attn   │  1D RoPE        │   │
│    │  1280d hidden  │  Causal mask  │  1280d hidden   │   │
│    │  20 heads      │  Group causal │  20 heads       │   │
│    │  AdaLN x6      │  Flow matched │  AdaLN x6       │   │
│    └─────────────────────────────────────────────────────┘  │
│                                                             │

│    Video predictions [B,16,T/4,H/8,W/8]                    │

│                                                             │

🔑 KEY NUMBERS TO REMEMBER

Experts:
  ✓ 24 DiT blocks each
  ✓ 1280 hidden dimension
  ✓ 20 attention heads
  ✓ 64 head dimension (1280/20)
  ✓ 3456 FFN dimension (2.7×)

VAE:
  ✓ 23 CausalConv3d layers
  ✓ 16-dimensional latents
  ✓ 4× temporal compression
  ✓ 8× spatial compression
  ✓ 5 downsampling stages

Attention:
  ✓ 6 AdaLN parameters per block (shift, scale, gate for MSA/MLP)
  ✓ 3 RoPE dimensions for video (temporal, height, width)
  ✓ 1 RoPE dimension for action (sequence)
  ✓ 4 attention patterns in MoT mask

Scheduling:
  ✓ 1000 noise timesteps
  ✓ 2 schedulers per modality (train/infer)
  ✓ Flow matching noise schedule
  ✓ Per-timestep loss weighting

✨ SPECIAL FEATURES DOCUMENTED

1. Mixture of Transformers (MoT)
   └─ Unified video-action attention with causal constraints

2. Group Causal Masking
   └─ Actions see first frame only (temporal consistency)

3. Flow Matching
   └─ Continuous diffusion with configurable noise schedule

4. Adaptive Layer Normalization (AdaLN)
   └─ Timestep-dependent modulation (6 params/block)

5. 3D Rotary Position Embeddings (RoPE)
   └─ Separate frequencies for temporal, height, width

6. Proprioceptive Encoder
   └─ Optional Linear layer for robot state (if proprio_dim provided)

7. First-Frame Conditioning
   └─ Optional: keep first frame fixed during training

8. Gradient Checkpointing
   └─ Memory-efficient training for 24-layer models
